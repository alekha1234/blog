# Publishing Guide

How to add notebooks to the blog and keep it healthy in search. For how the site should look,
see [DESIGN.md](DESIGN.md).

## How the site is built

- Every push to `main` runs [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml),
  which renders the site with Quarto and deploys it to GitHub Pages in about a minute.
- Notebooks are **not re-executed** on deploy. The outputs saved in the `.ipynb` are published
  as-is, so run the notebook top to bottom (*Restart & Run All*) before committing.
- Only the files listed under `project.render` in `_quarto.yml` are published: the homepage,
  About, 404 and every `*/*.ipynb`. The `Programming in Cpp/` and `Programming in Java/`
  folders and the Markdown docs stay in the repo only.

## Repository layout

```text
blog/
├── _quarto.yml               # Site config: navbar, sidebars, SEO, theme, filters
├── index.qmd                 # Homepage + homepage structured data (WebSite, Blog, Person)
├── about.qmd                 # About page
├── 404.qmd                   # "Page not found" page
├── styles.css                # Site styles
├── theme-fonts.scss          # Stops the Bootstrap themes downloading unused fonts
├── includes/seo_header.html  # Google Fonts link
├── seo-jsonld.lua            # Adds BlogPosting structured data to every article
├── lazy-images.lua           # Lazy-loads every image except the first on a page
├── images/                   # Favicon and default social-share image
├── time-series/              # Topic track: one notebook per article
├── DESIGN.md                 # Design system
└── PUBLISHING.md             # This guide
```

## Adding a topic track (e.g. `machine-learning/`)

Folder and file names become the page URL, so use **lowercase-kebab-case** with keywords
(no spaces, no underscores, no number prefixes). Reading order is set by `order:` and the
sidebar, not by the filename.

### 1. Create a topic folder in the root

```text
machine-learning/
├── supervised-learning-foundations.ipynb
├── linear-and-logistic-regression.ipynb
└── decision-trees-and-random-forest.ipynb
```

### 2. Add front matter to the first cell of each notebook

Make the first cell a **Raw** cell:

```yaml
---
title: "Supervised Learning in Python: Regression, Classification & Gradient Descent"
description: "Core concepts of regression, classification, cost functions, and gradient descent."
author: "Gujuri Alekha"
date: "2026-10-16"
order: 0
categories: [Machine Learning, Regression, Classification, Python]
image-alt: "One sentence describing the first chart in the notebook"
toc: true
number-sections: true
code-fold: show
---
```

- **title**: put the keywords people search for first; aim for under 60 characters.
- **description**: shown in Google results; keep it to 155 characters or fewer.
- **date**: use a fixed publish date. Avoid `date: last-modified`: CI checks out fresh files,
  so every post would show the deploy time.
- Use `##` for top-level sections inside the notebook; the page title is already the H1.
- Give each chart cell alt text with `#| fig-alt: "..."` as its first line.
- Don't publish Colab interactive tables, warnings or progress bars; clear them before committing.
- If you ever rename a published notebook, add the old URL under `aliases:` so existing links
  redirect.

### 3. Link the track in `_quarto.yml`

Add it to the navbar and give it its own sidebar:

```yaml
  navbar:
    left:
      - text: "Home"
        href: index.qmd
      - text: "📈 Time Series Track"
        href: "time-series/time-series-analysis-and-forecasting.ipynb"
      - text: "🤖 Machine Learning"
        href: "machine-learning/supervised-learning-foundations.ipynb"
  sidebar:
    - id: "machine-learning"
      title: "🤖 Machine Learning Track"
      style: "docked"
      contents:
        - "machine-learning/supervised-learning-foundations.ipynb"
        - "machine-learning/linear-and-logistic-regression.ipynb"
```

Readers get a docked sidebar listing the track in order, plus "Previous" / "Next" links at the
bottom of each article.

### 4. Preview, then push

```bash
quarto preview          # check it locally at http://localhost:4200/
git add machine-learning/ _quarto.yml
git commit -m "feat: add Machine Learning track"
git push origin main
```

### 5. Ask Google to index it

Once the deploy finishes, open Google Search Console → **URL Inspection**, paste the new
article URL and click **Request indexing**.

## SEO setup

- `sitemap.xml`, canonical links, Open Graph / Twitter cards and the favicon are generated by
  Quarto from `_quarto.yml`.
- Structured data: the homepage has `WebSite`, `Blog` and `Person` items (in `index.qmd`);
  every article gets a `BlogPosting` item from `seo-jsonld.lua`. The Person `@id` matches the
  portfolio's, so Google treats both sites as the same author.
- Google Analytics (`G-X9RX470F8T`, shared with the portfolio) is set in `_quarto.yml`.
- Search Console property: URL prefix `https://alekha1234.github.io/blog/`; sitemap
  `https://alekha1234.github.io/blog/sitemap.xml`.
